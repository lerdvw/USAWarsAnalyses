# USA Wars Analyses

Every US conflict from the Revolutionary War to 2026 as one Python dataset,
built up a step at a time.

| File | What it holds |
|---|---|
| `data.py` | The dataset: one record per conflict |
| `check.py` | Sanity checks; run after every change |
| `project_conventions.md` | How this repo is worked on |

```bash
python3 check.py
```
